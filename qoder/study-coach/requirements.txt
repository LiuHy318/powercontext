# IMPORTANT — what this project actually needs at runtime is TWO different things:
#
#   1. The POWERCONTEXT SDK + SERVER + CLI. This is a real, published package on
#      PyPI (`powercontext`), and StudyRecall needs three of its extras:

#
#          pip install "powercontext[client,cli,server]==1.2.0"
#
#      1.2.0 is the closest public release to the runtime this build was developed
#      and tested against. The development machine had an *editable* sibling
#      checkout at commit d0813396beea304b4ded9911f516dbea1a28b58e
#      (version 1.2.1.dev3+gd0813396b), which is the official competition baseline
#      9db1753434162c0aa7c9f1189a1722e617880a52 plus PDF-only commits. All core
#      interfaces used here (create_scope/list_scopes, create_source/list_sources,
#      remember_memory/revise_memory_entry/list_memory_entries, search_memory FTS,
#      and the Source/Scope `next_cursor` pagination cursors) are the stable public
#      HTTP API. This exact `pip install "powercontext[client,cli,server]==1.2.0"`
#      into a CLEAN virtualenv (no --system-site-packages) was used to re-run the
#      full 19-test suite green; see docs/VERIFICATION.md.
#
#   2. The web app + test tooling, listed at the bottom of this file.
